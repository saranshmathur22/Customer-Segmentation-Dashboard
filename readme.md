# 📊 Customer Segmentation Dashboard

An interactive **Power BI dashboard** built to analyze customer segments, purchasing behavior, and revenue performance. This project helps businesses identify high-value customers, understand spending patterns, and make data-driven decisions using interactive visualizations.

---

## 📸 Dashboard Preview

![Customer Segmentation Dashboard](C:/Users/saran/Desktop/dashboard/Dashboard.png)

---

## 🚀 Project Overview

This dashboard provides a comprehensive analysis of customer data through interactive KPIs and visualizations. Users can filter the dashboard by **Region, Preferred Channel, Gender, and Preferred Category** to explore customer behavior across different segments.

---

## ✨ Key Features

- 📌 Executive KPI Cards
- 👥 Customer Segmentation Analysis
- 💰 Revenue Analysis by Customer Segment
- 🛍️ Revenue Analysis by Product Category
- 📈 Customer Behavior Scatter Analysis
- 🎛️ Interactive Slicers
- 🌙 Modern Dark Theme Dashboard

---

## 📊 Dashboard KPIs

- Total Customers
- Total Revenue
- Average Order Value
- Average Purchase Frequency
- Average Satisfaction Score
- Total Customer Segments

---

## 📈 Visualizations Included

| Visualization | Purpose |
|--------------|---------|
| KPI Cards | Business summary |
| Donut Chart | Customer segment distribution |
| Bar Chart | Revenue by segment |
| Scatter Plot | Customer purchase behavior |
| Treemap | Revenue by product category |
| Interactive Slicers | Dynamic filtering |

## 📊 Business Insights

- High-Value Loyalists generate the highest revenue.
- Budget Shoppers represent the largest customer segment.
- Revenue distribution varies significantly across product categories.
- Customer behavior can be analyzed based on purchase frequency and average order value.
- Interactive filters provide deeper insights into customer demographics and purchasing patterns.

## ▶️ How to Use

1. Clone this repository.
2. Open `Customer_Segmentation_Dashboard.pbix` in Microsoft Power BI Desktop.
3. Explore the dashboard using the interactive slicers.
4. Analyze customer segments and business insights.
